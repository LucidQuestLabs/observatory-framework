# Deployment Modes

## Open-Source Public Mode

Use for public education and civic transparency.

- Public repository.
- Redacted sources only.
- Public-ready reports.
- Clear methodology.
- Community contribution guidelines.

## Internal Investigation Mode

Use for sensitive research.

- Private repository.
- Restricted sources.
- Internal notes.
- Legal review flags.
- Publication controls.

## Client Consulting Mode

Use for paid analysis.

- Client-specific targets.
- Restricted workspace.
- Deliverable memos.
- Executive briefings.
- Optional public/private split.

## Hybrid Civic Mode

Use for public-interest work with restricted working files.

- Private analysis layer.
- Public-facing reports.
- Redacted source summaries.
- Community briefings.

## Static Publishing / Netlify

The `site/` directory is intentionally simple and can be published by Netlify without a build step. It should expose methodology and public-ready reports, not raw restricted investigation materials.
