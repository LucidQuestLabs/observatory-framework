# Faux Data Policy

Faux data is synthetic demonstration material used to test Observatory Framework workflows. It is not evidence and must not be mixed with real investigative claims without clear labeling.

## Rules

- Mark faux targets, sources, observations, dossiers, and briefings as synthetic.
- Do not use real private individuals.
- Use fictional entities, agencies, document titles, and URLs.
- Keep fictional geography plausible but clearly labeled.
- Do not imply that a real company, agency, or person took an action unless a real source supports it.
- Use faux data to validate workflow, schema fit, review flow, ledger behavior, report generation, and publication surfaces.

## Labeling

Every faux output should include:

```text
Synthetic demonstration data. Not a real source-backed claim.
```
