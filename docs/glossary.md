# Glossary

Observation: Atomic source-backed claim.

Ledger: Append-only record of approved observations.

Target: Facility, entity, jurisdiction, or issue being investigated.

Source: Evidence artifact used for extraction.

Review packet: Agent-produced packet for human approval.

Confidence: Estimate of support strength: low, medium, or high.

Interpretation level: Direct, inferred, or speculative.

Public/private hybrid: Deployment model where some data is public and some remains restricted.

Dossier: Structured report generated from observations.

Red team: Agent or human process for finding weaknesses.

Supersession: New record that corrects or replaces an old one without deleting it.

Snag: A blocker, surprise, ambiguity, tool failure, or process lesson captured so it can be triaged and folded back into the framework.
