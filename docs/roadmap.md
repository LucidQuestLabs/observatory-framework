# Roadmap

## Phase 0: Setup

- Create repository skeleton.
- Add SOPs, schemas, prompts, and templates.
- Add append-only ledgers.
- Add first target profile.

## Phase 1: First Target Packet

- Select one data center, cluster, or issue lens.
- Register 10-25 sources.
- Extract 20-50 pending observations.
- Prepare review packet.

## Phase 2: First Mini-Dossier

- Review and approve first observation batch.
- Append approved observations to ledger.
- Generate mini-dossier from approved observations.
- Record open questions and next actions.

## Phase 3: Repeatability Test

- Run the process on a second target.
- Identify friction in SOPs, schemas, and templates.
- Adjust workflow without breaking the append-only record.
- Review `snags/snag_log.md` and fold repeated lessons into the corpus.

## Phase 4: Lightweight Automation

- Validate JSONL ledgers.
- Build source indexes and simple dossier drafts.
- Export public-ready data to the static site.
- Track automation failures and deployment assumptions as snags.

## Phase 5: Dashboard Prototype

- Target list.
- Source list.
- Pending observations.
- Review decisions.
- Ledger view.
- Dossier export.
