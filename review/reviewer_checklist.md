# Reviewer Checklist

- [ ] Sources are valid and traceable.
- [ ] Source access levels are appropriate.
- [ ] Observations are atomic.
- [ ] Source locations are clear enough for re-checking.
- [ ] Confidence levels are justified.
- [ ] Interpretation levels are accurate.
- [ ] Claims are not overstated.
- [ ] Privacy sensitivity is reviewed.
- [ ] Publication status is correct.
- [ ] Corrections or supersessions are recorded as new entries.
