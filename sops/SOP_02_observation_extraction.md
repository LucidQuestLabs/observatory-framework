# SOP 02: Observation Extraction

## Purpose

Convert sources into atomic, source-backed observations that can be reviewed and preserved.

## Rules

- One observation per claim.
- Do not combine evidence, interpretation, and recommendation in one record.
- Do not editorialize.
- Do not include unsupported allegations.
- Include source IDs and source locations.
- Label confidence and interpretation level.
- Default review status is `pending`.

## Procedure

1. Read the source and identify discrete claims.
2. Check whether each claim is directly supported, inferred, or speculative.
3. Assign category and risk tags.
4. Attach source IDs and source location metadata.
5. Write concise observation text.
6. Add confidence and confidence reason.
7. Add publication status.
8. Place the observation in a pending file or review packet.
