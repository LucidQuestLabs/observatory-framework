# SOP 03: Confidence Scoring

## Purpose

Use consistent confidence ratings across agents and reviewers.

## Levels

`high`: Directly supported by a primary source or multiple independent reliable sources, with clear source location.

`medium`: Supported but incomplete, ambiguous, or based on credible secondary evidence.

`low`: Plausible but weakly sourced, inferred from limited evidence, or requiring confirmation.

## Adjustment Rules

- Downgrade if the source location is missing.
- Downgrade if the claim depends on ambiguous wording.
- Downgrade if only tertiary evidence exists.
- Upgrade only when support is direct, traceable, and reliable.
- Mark contradictions explicitly rather than hiding uncertainty in a confidence score.
