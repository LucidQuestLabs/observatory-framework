# SOP 08: Agent Coordination

## Purpose

Allow multiple agents or tools to work on the same investigation without losing provenance or reviewability.

## Coordination Rules

- Each agent states role, target, inputs, outputs, and assumptions.
- Agents write artifacts, not final truth.
- Handoffs include unresolved questions.
- Agents do not approve their own observations.
- Review status changes require human authorization.

## Handoff Format

```markdown
# Agent Handoff

- From:
- To:
- Target:
- Scope:
- Inputs used:
- Files changed:
- Proposed observations:
- Open questions:
- Risks or sensitivities:
- Recommended next step:
```
