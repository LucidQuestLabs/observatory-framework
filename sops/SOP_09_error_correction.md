# SOP 09: Error Correction

## Purpose

Correct mistakes while preserving the historical record.

## Procedure

1. Identify the error and affected records.
2. Classify severity.
3. Add correction record.
4. Add replacement observation if needed.
5. Mark supersession links.
6. Update reports that relied on the affected observation.
7. Add reviewer notes.

## Error Severity

- `minor`: Typo, formatting issue, or non-substantive metadata repair.
- `moderate`: Source mismatch, confidence problem, or unclear wording.
- `major`: Incorrect claim, unsupported allegation, privacy issue, or publication risk.
